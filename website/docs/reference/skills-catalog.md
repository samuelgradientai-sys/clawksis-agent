# Bundled Skills Catalog

Clawksis ships with a large built-in skill library copied into `~/.clawksis/skills/` on install. Each skill below links to a dedicated page with its full definition, setup, and usage.

Clawksis also syncs bundled skills on `clawk update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from your profile's `~/.clawksis/skills/` tree, it is still shipped with Clawksis; restore it with `clawk skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.
